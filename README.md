# 하이클린 확인서 출력

설치확인서와 A/S 확인서를 고객정보가 채워진 상태로 바로 인쇄하는 웹 프로그램입니다.

- 접속: https://hihi68658561-code.github.io/hiclean-confirm/
- 고객 데이터: Supabase(서울)에 저장되며, 등록된 직원만 로그인해서 볼 수 있습니다.
- 처음 설정: `supabase/setup.sql`을 Supabase SQL Editor에서 실행하고, `supabase/first_admin.sql`로 대표 계정을 관리자로 등록합니다.
- 이 저장소에는 고객 정보가 들어 있지 않습니다. 페이지에 들어 있는 Supabase 공개용 키(publishable)는 로그인과 권한 규칙으로 보호됩니다.
